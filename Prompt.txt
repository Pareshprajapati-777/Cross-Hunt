Existing Cross-Hunt project ko complete audit karke production-level improve karo. Pehle existing code/database samjho, phir changes karo. Working features ko break mat karo.

### 1. REAL INDIA SHIP DATA
India ke **public + private cruise/ship/yacht/boat operators** ka real data system me add karo.

Data:
- Company/operator name
- Ship/vessel name
- Ship type
- Model
- Size/length
- Capacity
- AC/non-AC
- Location
- Departure
- Destination
- Route
- Duration
- Price
- Price unit
- Facilities
- Food
- DJ/music
- Decoration
- Photography
- Water sports
- Extra services
- Contact number
- WhatsApp number if verified
- Email
- Website
- Booking URL
- Source
- Last verified date

Real examples me pricing ka format bahut different hai: kuch operators per-boat/hour charge karte hain, kuch per-person/ticket, aur kuch quote-based hain. Isliye price unit database me mandatory rakho.

**IMPORTANT:**
Ye external/public operators automatically Owner account nahi hain.

Unko:
`PUBLIC OPERATOR / EXTERNAL OPERATOR`

ke form me store karo.

Unke liye fake login/account create mat karo.

Actual platform Owner sirf tab banega jab wo platform par register/onboard hoga.

### 4. LOW PRICE FIX
Jin ships ka rate unrealistically low aa raha hai unko identify karo.

Price calculate karte waqt:
- price unit check karo
- duration check karo
- capacity check karo
- per-person vs per-boat confuse mat karo
- GST/tax check karo
- extra charges check karo

Example ₹5,000 agar `per person` hai to usko whole-boat ₹5,000 mat dikhao.

Backend me price validation rakho.

Suspicious price ko Admin Review me bhejo.
